# Release download guide

You normally need **one installer**, not the whole asset list. Open the [latest release](https://github.com/colewinstead/VeriCivil/releases/latest) and use its download table, or use [VeriCivil downloads](https://vericivil.com/downloads) for the branded edition.

## Choose your computer and edition

In the filenames below, `<version>` is the release number, such as `1.9.2`.

| Computer | VeriCivil edition: usual download | Neutral edition: no VeriCivil branding |
| --- | --- | --- |
| Windows x64 | `VeriCivil-Superelevation-<version>-win-x64-unsigned.exe` | `Superelevation-Calculator-<version>-win-x64-unsigned.exe` |
| Mac with Apple Silicon (M-series) | `VeriCivil-Superelevation-<version>-mac-arm64-unsigned.dmg` | `Superelevation-Calculator-<version>-mac-arm64-unsigned.dmg` |
| Mac with an Intel processor | `VeriCivil-Superelevation-<version>-mac-x64-unsigned.dmg` | `Superelevation-Calculator-<version>-mac-x64-unsigned.dmg` |

The two editions share the calculator and Python engine. Their branding, installed application identities, local profiles, and update feeds differ. Keep the same edition when updating. The website's download page offers the VeriCivil edition; the release table offers both.

The Windows `.exe` installs the app, creates shortcuts and an uninstaller, and supports approved in-app updates. On Mac, open the `.dmg` and copy the app to Applications; these unsigned Mac builds require manual updates. `arm64` means Apple Silicon; `x64` means Intel Mac or 64-bit Intel/AMD Windows, according to the filename.

**Unsigned evaluation builds:** these downloads are not publisher-signed or notarized. Windows updates use HTTPS and SHA-512 checksums without publisher-signature verification. See the [code signing policy](https://vericivil.com/code-signing).

## Why are there 34 assets?

The [v1.9.0 release](https://github.com/colewinstead/VeriCivil/releases/tag/v1.9.0) has 32 uploaded files plus two [source archives generated by GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases). They are not 34 different versions of the calculator.

| Group | Count | Purpose |
| --- | ---: | --- |
| Normal desktop packages | 10 | Two editions, each with one Windows `.exe`, two Mac `.dmg` files, and two alternative Mac `.zip` packages. Most users choose one `.exe` or `.dmg`. |
| Desktop preview packages | 6 | Two editions across Windows, Apple Silicon, and Intel Mac. Windows previews are portable `.zip` folders; Mac previews are separate `.dmg` builds. These use preview identities and are optional alternatives to the installed app. |
| `SHA256SUMS-*.txt` | 13 | Integrity checks for the browser archive (1), preview packages (6), and installer groups (6). They contain hashes, not software. |
| `latest-*-unsigned-win32-x64.yml` | 2 | One update feed per edition. The Windows updater reads these to locate and verify the matching installer. Do not open or install them yourself. |
| `Superelevation-Browser-<version>.tar.gz` | 1 | Browser build archive for hosting/deployment, not a desktop installer. |
| GitHub `Source code (zip)` and `Source code (tar.gz)` | 2 | Source snapshots for developers. They are not compiled applications and do not include an installed desktop runtime. |
| **Total** | **34** | **Normally download just one desktop installer.** |

The extra files preserve multiple editions, architectures, previews, integrity checks, and Windows updates. They are not all necessary for an individual user. Reducing the list would mean retiring variants or changing release packaging; this guide keeps those supported downloads and update feeds intact. Counts can change in future releases.

## What do the other filenames mean?

- `Superelevation-Desktop-Preview-...` is the VeriCivil preview. `Superelevation-Calculator-Desktop-Preview-...` is the neutral preview. A Windows preview ZIP must be extracted as a whole before running its executable; it does not use the installer's in-app update flow.
- `...-mac-...-unsigned.zip` is an alternative compressed Mac application package from the installer build. It is not a Windows portable app. Prefer the matching `.dmg` for a normal Mac installation.
- `SHA256SUMS-installers-...` checks the installer packages for that edition and platform. `SHA256SUMS-electron-...` checks a preview; `SHA256SUMS-browser.txt` checks the browser archive. A checksum verifies that your download matches the published bytes; it does not establish publisher identity.
- Update-feed files and the installers they name must stay together on the release. Removing or renaming either can break in-app updates.

## Testing the Windows updater fix

Version **1.9.2** changes **Restart and install** to apply an approved update silently in the existing installation and reopen the app. Saving work and explicit download/restart approval are still required.

When updating an older installed version to 1.9.2, the older app still controls that first installer handoff: you may need to finish the wizard and reopen the app manually once. To test the corrected handoff, install 1.9.2 and then update to a later published version. Installing 1.9.2 alone does not test an update initiated by 1.9.2.
