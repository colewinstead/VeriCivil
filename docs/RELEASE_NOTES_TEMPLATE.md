## Download the desktop app

Choose **one installer** for your computer. Existing users should keep the same edition.

| Computer | VeriCivil edition | Neutral edition (no VeriCivil branding) |
| --- | --- | --- |
| Windows x64 | [Windows installer](https://github.com/colewinstead/VeriCivil/releases/download/{{TAG}}/VeriCivil-Superelevation-{{VERSION}}-win-x64-unsigned.exe) | [Windows installer](https://github.com/colewinstead/VeriCivil/releases/download/{{TAG}}/Superelevation-Calculator-{{VERSION}}-win-x64-unsigned.exe) |

**Why so many assets?** Most users can ignore the portable previews, browser build, and source archives. `SHA256SUMS-*.txt` files verify downloads; `.yml` files support Windows updates. [Read the download guide and full asset breakdown](https://github.com/colewinstead/VeriCivil/blob/{{TAG}}/docs/RELEASE_ASSETS.md).

**Unsigned Windows evaluation builds.** Code signing work and Mac desktop builds are paused. Windows installers support user-approved updates without publisher-signature verification; portable builds require manual replacement. [Code signing policy](https://vericivil.com/code-signing).
