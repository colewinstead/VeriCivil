# Guardrail browser calculator

Mode: Operate. Extend VeriCivil's existing calculator family using its current tokens, header, native form controls, measurement typography and responsive behavior. The user explicitly selected the existing calculator patterns; this is not a new visual identity or an open concept exercise.

## Direction contract

THESIS: Make both exposure directions and the accepted calculation inputs reviewable together, without a marketing hero or decorative roadway diagram.

OWN-WORLD: Inherit VeriCivil's dark paper/panel surfaces, teal actions, amber unsaved state, familiar control borders and monospaced measurements. Keep the global design system unchanged.

STORY: Enter roadway and barrier inputs, review near/opposing lengths and governing limitations, optionally add project metadata, save/reopen JSON or download the existing PDF with optional references.

FIRST VIEWPORT: Compact title and runtime state, project-file toolbar, then grouped inputs on the left and the near/opposing review table with PDF controls on the right. On phones, inputs lead and results follow at readable size.

FORM: User-pinned extension of the existing calculator workspace; code-led, no seed or composition tournament needed for the confirmed existing interface patterns. Signature interaction is automatic Python calculation with immediate hiding of obsolete results and export blocking until the current inputs are accepted.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Constraints: preserve all upstream calculation modes, all three PDF styles, optional facility-specific references, free access, versioned local JSON files and unsaved-change protection. No DXF, LandXML or cloud project storage. Show source revision and inherited engineering limitations without claiming engineering approval.
