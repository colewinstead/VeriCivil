# Typicals component editing

Mode: Operate. Extend the existing VeriCivil engineering workspace. The user rejected the fixed two-lane form and oversized catalog schematic and requested additional lanes, barriers, ditches, retaining walls and general customization.

## Direction contract

THESIS: A roadway section is an ordered set of connected engineering components, editable through a compact component stack beside its actual drawing.

OWN-WORLD: Inherit DESIGN.md's green neutral appearance pairs, system controls, tabular measurements and restrained borders. CAD uses imported workspace colors; sheet output remains independent.

STORY: Choose a side, select or add a component, edit dimensions, move/duplicate/remove it, inspect exact connections, and save/reopen the same section. Existing projects upgrade without changing their geometry.

FIRST VIEWPORT: A 340px inspector shows the active side's bounded component list, add selector and selected properties. The drawing remains dominant; exports stay visible. The directory uses equal bounded previews with an authentic editor capture.

FORM: Code-led extension of a settled workspace and the user's supplied DOT-detail reference. No concept roll or replacement brand; no seed is invented.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
